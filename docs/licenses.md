# Licenses: policy and review notes

PocketAnon is `MIT OR Apache-2.0`. Everything it links, bundles or downloads must be
permissive. `cargo deny check` enforces the allowlist in `deny.toml`;
`THIRD-PARTY-LICENSES.md` is the shipping notice file, generated by cargo-about from
`about.hbs` plus a hand-written header for the things cargo-about cannot see (models, fonts,
native libraries). CI (`.github/workflows/licenses.yml`) fails if either drifts.

## Allowlist rationale

| Identifier | Why it is on the list |
|---|---|
| MIT, Apache-2.0 (incl. LLVM exception), BSD-2/3, ISC, Zlib, BSL-1.0, 0BSD, Unlicense | Standard permissive licenses. Notice duty only. |
| Unicode-3.0 | ICU4X crates (`icu_*`, `zerovec`, …) via `idna`/`url`. Permissive. |
| CDLA-Permissive-2.0 | `webpki-roots` (Mozilla CA bundle) via `ureq`/`rustls`. Permissive data license. |
| MPL-2.0 | `option-ext` only (via `directories`). File-level copyleft; we ship it unmodified, so only the notice applies. |
| OFL-1.1, Ubuntu-font-1.0 | Fonts bundled by `epaint_default_fonts` and Wordcraft. Must ship the license text; fonts may not be sold on their own. |

Dual-licensed crates whose *options* include copyleft (`self_cell`: Apache-2.0 OR GPL-2.0;
`r-efi`: MIT OR Apache-2.0 OR LGPL-2.1) are used under the permissive option.

## Things cargo-about does not see

- **ONNX Runtime 1.20** (MIT, Microsoft): `ort-sys` downloads prebuilt binaries from pyke.io
  at build time (`dist.txt` in the crate lists URLs and SHA-256 sums).
- **Oniguruma** (BSD-2-Clause): vendored C source compiled by `onig_sys` (via `tokenizers`).
- **Wordcraft** (git pin, MIT OR Apache-2.0): bundles OFL fonts and hyphenation patterns
  (CC0, MIT, BSD-3). Its `docs/brand/` trademarks are not open source and are not used here.

## Models

Both registry models are Apache-2.0. The `onnx-community/*` repositories carry no license
field of their own; they are unmodified ONNX conversions that declare the upstream model as
`base_model`, so the upstream license governs.

| Registry id | Lineage |
|---|---|
| `gliner_multi_pii_v1` | onnx-community/gliner_multi_pii-v1 ← urchade/gliner_multi_pii-v1 (Apache-2.0) ← urchade/gliner_multi-v2.1 (Apache-2.0) ← microsoft/mdeberta-v3-base (MIT). Fine-tuning data: urchade/synthetic-pii-ner-mistral-v1 (Apache-2.0, synthetic). |
| `gliner_small_v2_1` | onnx-community/gliner_small-v2.1 ← urchade/gliner_small-v2.1 (Apache-2.0) ← microsoft/deberta-v3-small (MIT). Training data: urchade/pile-mistral-v0.1 (Apache-2.0). |

**Do not add GLiNER v0 or v1 models** without re-checking: those were CC-BY-NC-4.0 because of
Pile-NER training data. Only the v2.1 line (NuNER/pile-mistral data) is Apache-2.0.

Caveat: `pile-mistral-v0.1` is Pile text with LLM-generated annotations; the Pile's provenance
is mixed. That is a training-data question, not a license conflict, and is normal for this
class of model.

## Advisory exceptions (`deny.toml`)

- `zip 3.0.0` (RUSTSEC-2026-0367/0368/0369): pinned by Wordcraft. All three advisories concern
  `ZipArchive::extract` / `ZipStreamReader::extract`, which Wordcraft does not call (grep of
  the pinned revision finds no `extract(`); it reads DOCX entries into memory. Revisit when
  Wordcraft moves to zip ≥ 4.
- `unmaintained = "workspace"`: only direct dependencies are flagged. Transitive unmaintained
  crates (`paste`, `number_prefix`, `zbus_names`, `zvariant`) belong to egui, indicatif and
  tokenizers.

## Regenerating

```sh
cargo deny check
cargo about generate about.hbs -o THIRD-PARTY-LICENSES.md
```
